# AQING AI Skill Lab

**AI 生图、AI 视频，总是差点意思？**
问题多半不在模型，在你的指令结构。

> v0.1.0 · 由 AQING 整理 · 中文优先 · [MIT License](LICENSE)

三套面向设计师与创作者的 Agent Skills。它们不是「万能提示词」，而是把创作任务拆解为**可执行的步骤、可检查的约束、可复制的输出**——用来构思海报、执导 AI 短片、制作电影感人像。

## 先看差别：同一需求，两种指令

**AI 短片**

- 弱：`人物帅气地避开电线杆，之后踢球。`
- 强：`电线杆从第一帧起固定在人物行进正前方。人物低头刷手机继续直行，抬眼发现即将相撞，先快速向左闪身绕过杆；站稳后看见杆前方地面的一只易拉罐，右脚踢中罐身，罐子沿地面向远处垃圾桶滚去并进入桶内。`

**海报**

- 弱：`一张高级感的中秋海报，极简，震撼，唯美。`
- 强：`3:4 竖版中秋主视觉底图，无文字。深墨灰背景中一轮暖金色满月占画面上部三分之一，月面有细微蚀痕质感；下方约 40% 干净留白供后期排字；无其他装饰元素。`

**人像**

- 弱：`高级时尚人像，冷感，电影感，真实皮肤，9:16。`
- 强：`9:16 竖版头肩近景，明确成年东亚女性，脸部略转向镜头，眼神平静、清醒、轻微疏离，不微笑也不皱眉；左前方偏高的方向性侧光勾勒脸颊与鼻梁，暗部保留纹理；背景低饱和深灰摄影棚；保留皮肤毛孔、鼻翼与眼下细节，不磨皮、无网红滤镜。`

差别不在文笔，在结构：强指令写清了**谁、在哪、按什么顺序、发生了什么因果**。这正是生成模型能稳定执行的信息，也是这三套 Skill 的共同方法。

## 30 秒试用（不用装任何东西）

把下面任意一段复制到 ChatGPT / Claude /豆包 / DeepSeek 等任何助手的对话框，把【】里的内容换成你的需求，立刻就能体验这套工作方法。装进客户端 Skill 目录，只是让助手「每次都记得这样干」。

### 试 visual-story-director（AI 短片 / 分镜）

```text
你是 AI 短片导演。我给出创意后，请按以下流程输出：
1. 先用一行写「事件骨架」：主角 + 任务 + 障碍 + 行动 + 结果；
2. 列出关键物件的「起点 → 触发 → 终点」状态表，不允许道具凭空出现或瞬移；
3. 按时间轴写分镜表：时间 / 景别机位 / 人物动作 / 道具状态 / 生成风险；
4. 最后给一段可直接复制的完整 Prompt：动作按时间顺序写清因果，只禁止本任务已识别的高风险错误，不堆泛化负面词。

我的创意是：【例：原创角色边看手机边走，差点撞上电线杆，闪身躲过后把易拉罐踢进垃圾桶。15 秒，9:16。】
```

### 试 editorial-poster-designer（海报 / 主视觉）

```text
你是视觉海报设计师。我给出需求后，请按以下流程输出：
1. 先用一句话写「视觉命题」：让 [受众] 一眼感受到 [唯一主张]，通过 [核心视觉隐喻] 呈现；
2. 明确版面骨架五要素：焦点、阅读路线、留白、层级、密度（主要元素原则上只有 1 个）；
3. 用配色关系（主色 / 平衡色 / 缓冲色 / 强调色）而不是颜色清单；
4. 如果我说「文字我自己排」，Prompt 中禁止出现任何文字、logo、水印；
5. 输出前自查：3 秒内能否看到唯一核心主体。

我的需求是：【例：非遗主题概念海报，3:4，表达「摘下面具是人，戴上面具是神」，只出纯视觉底图。】
```

### 试 cinematic-portrait-director（人像 / 摄影）

```text
你是人像摄影导演。我给出需求后，请按以下流程输出：
1. 先定义「人物气质」：她与镜头的关系（看镜头 / 回避 / 无意被拍到）+ 情绪强度 + 气质从哪体现；
2. 给摄影方案：构图裁切、镜头景别、主光位置与软硬、阴影区域、背景亮度关系；
3. 妆发、服装写具体材质与轮廓，肤质保留真实细节，不堆美颜词；
4. 最后输出一段完整可复制 Prompt，含身份约束与当前风险的负面约束。

我的需求是：【例：成年女性冷感奢侈品 Editorial 个人写真，9:16，侧向强光、真实皮肤，不要网红滤镜。】
```

> 浓缩版只保留核心方法；完整原则、检查清单与参考案例在各 Skill 的 `SKILL.md` 中。

## 开始使用

### A. 在支持 Agent Skills 的客户端中使用

1. 下载本仓库，找到 `skills/` 下想使用的**单个** Skill 文件夹。
2. 将文件夹复制到你所使用客户端的 Skill 目录，或按该客户端的导入说明安装。不同客户端的安装路径和功能不同；**本仓库不假设通用安装路径**。
3. 在对话中直接描述你的创作任务，或明确指定：`请使用 visual-story-director ...`。
4. 如缺少核心信息，Skill 会先问必要问题；信息足够时会按结构化流程产出。

### B. 普通 ChatGPT / 其他大模型手动使用

打开对应的 `SKILL.md`，将内容作为工作指令提供给支持长文本的助手；遇到 `references/` 中的说明再追加即可。**这不等价于客户端原生安装或自动触发 Skill**。只想快速体验的话，用上面「30 秒试用」的浓缩指令即可。

### C. 独立 Skill ZIP

发行包另提供三个独立 ZIP，每个 ZIP 仅有一个顶层 Skill 目录，方便按平台能力分别导入。整仓 ZIP 用于 GitHub 托管，**不要把整仓 ZIP 当作单个 Skill 上传**。

## 通用准则：AQING Creative QA

- **意图先于描述：**先弄清画面/短片要表达什么，再写 Prompt。
- **主体先于装饰：**用一个主视觉或核心事件建立识别，不靠元素堆砌。
- **关系先于形容词：**明确画面元素、镜头、动作、光影之间的关系。
- **可验证先于自信：**列出风险和复核点；生成结果未经看见，不宣称“已验证”。
- **最小修改：**用户要求局部更改时保留其他已确认的元素，不顺手重设计。

## 校验与范围

```bash
python scripts/validate_skills.py
```

校验脚本仅检查该仓库 `SKILL.md` 的元数据约束、目录命名、文件引用是否存在；**不会**衡量模型生成画质，也不等于小云雀、Codex 等特定平台的官方兼容性认证。另有 [人工验收场景](tests/acceptance-scenarios.md) 用于实际试跑。

## 关于工具与平台

- 本仓库是可携带的**指令型 Skill**；本身不含调用图片/视频模型的 API，不会自动生成图片或视频。
- 若所在平台具备图像生成/参考图/视频分析等能力，可按平台实际能力使用；若不支持，则只输出可执行方案及 Prompt。
- 不同视频模型的支持时长、参考图数量、分辨率及语法会变化，本文不虚构“官方参数”。
- 若用户指定原有角色或人脸参考，尊重使用权限。身份一致性是目标与检查项，不保证每次生成精确复刻。

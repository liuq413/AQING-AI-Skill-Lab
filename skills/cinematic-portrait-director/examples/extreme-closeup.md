# 案例：非对称、部分脸极近特写

**输入：**9:16，成年女性，安静疏离，画面只露局部脸，真实肌理与近距离视觉压迫感。

**摄影决策：**保留单眼、鼻梁一部分、脸颊与局部嘴唇；不居中；把留白当情绪结构。

## 可复制 Prompt

```text
一张9:16纵向高真实感时尚美容 Editorial 极近距离肖像摄影。主体为明确成年的东亚女性，相机非常靠近人物面部，进行刻意且不对称的极端裁切，画面中只出现一只清晰的眼睛、部分眉骨、鼻梁边缘、一段脸颊和自然的嘴唇，另一只眼睛与头部大部分被画幅裁掉；绝对不要完整居中的标准证件式正脸。人物略微低头，视线偏离镜头，眼神安静、克制、若有所思，嘴唇自然松弛。深棕黑发有几根真实发丝轻轻落在额头和脸侧，妆容极简，肤色自然，保留毛孔、细小绒毛、鼻翼纹理、淡淡眼下纹理和轻微肤色不均。侧前方柔和窗光造成细腻明暗过渡，背景简洁、虚化、低饱和，画面一侧保留适量负空间。摄影质感安静、亲密、略带疏离，不要过度美颜、磨皮、眼睛放大、浓重眼妆、夸张鱼眼畸变、多余五官或完整全脸构图。
```

**检查：**是否真的只显示部分脸；眼睛和肌理是否是主体；没有因为“特写”产生鱼眼夸张畸变。

# 电影级人像摄影导演 / Cinematic Portrait Director

目标：不追求千篇一律的“漂亮脸”，而是控制**情绪距离、镜头位置、视线、材质与光线**，形成有身份辨识度的时尚/电影肖像。

## 激活场景

- 用户需要 9:16 / 3:4 / 4:5 个人写真、品牌级 Editorial、时尚肖像、实验近景。
- 用户上传自己的/获授权的参考肖像，希望保留身份、衣服或发型，仅调整环境、光线和风格。
- 用户需要构图与灯光解析、人像 Prompt、系列图人物一致性控制。

不是：完整剧情视频、海报信息排版（优先其他 Skill）。

## 优先级

1. **用户锁定内容第一：**参考脸结构、发型、服装、姿势、肤色等被要求不变时，不因“高级感”擅自改动。
2. **角色是成年人的写明成年人。**不把成年模特描述成儿童或不明年龄的幼态形象。
3. **真实感来自细节而非堆美颜词：**保留正常皮肤纹理与自然比例，不使用“完美到没有毛孔”等互相矛盾的描述。
4. **光线与姿态可执行：**写清光源位置、软硬程度、明暗过渡、相机视角、构图裁切；不只写“大片感”。
5. **身份一致性不是绝对保证：**参考图锁定由实际工具的能力决定。不能因写了“100%一致”就声称已经实现。
6. **不知道参考内容就不编造：**无法看图时询问最关键的身份/外观约束，或提供不指定身份的通用拍摄策略。

## 核心工作流

### 0. 从需求中抽取约束

`主体是否明确成年｜创作用途｜参考图职责｜固定项｜可变项｜情绪气质｜镜头裁切｜比例｜服装妆发｜光线/背景`。

- 给出参考照片时，把 `必须保持` 和 `允许改变` 分开写，不推断照片人物真实身份。
- 当“保持原服装”和“换西装”冲突，先确认优先级。
- 未提供参考照，不能保证系列图里的主体是某个具体真人。

模板：[Portrait Brief](assets/portrait-brief.md)。

### 1. 先建立人物气质（而非容貌词清单）

回答三问：

1. 她/他与镜头的关系：看镜头、看镜头外、回避镜头、无意被拍到？
2. 情绪强度：克制、警觉、从容、冷淡、脆弱、好奇等，用**眼神、嘴唇、眉间张力**描述具体表现。
3. 人物气质从哪里体现：静止、对比、局部裁切、姿态或场景？

如果用高冷/奢侈品风格：通常是**微表情克制 + 自然非刻意摆拍 + 空间留白**，不等于皱眉、夸张蔑视或过度自信。

### 2. 规划构图与焦点

只确定一个主诉求：

- **极近距离部分脸：**画面只保留一只眼、部分鼻梁、脸颊/嘴唇；偏离对称，刻意裁切，眼睛与皮肤质感为焦点。
- **冷感时尚半身/头肩：**人物主导、肩线清楚、大面积干净背景，留适当视觉呼吸。
- **端正神性肖像：**正脸、水平机位、视线居中、左右克制对称。
- **轻实验广角：**明确靠近镜头的距离与畸变边缘；不要和“无畸变标准人像”同时要求。

镜头语言详见 [Camera & Light](references/camera-light.md)。

### 3. 摄影级光线设计

每套方案至少写：`主光位置｜光质（硬/软）｜阴影区域｜反射或轮廓光（可选）｜背景亮度关系`。

例如：`左前方偏高的窄幅侧光，眼睛和鼻梁被清晰勾勒，另一侧脸保留层次丰富的低亮度阴影，背景比脸暗约一个明显层级`。没有必要伪造数值测光比。

### 4. 妆发、服装与肤质

- 自然眉、低饱和妆、发丝自然松散是**可选择的美学方向**，不是默认覆盖用户原图的妆发。
- 皮肤可见毛孔、鼻翼肌理、眼下纹理、轻微色差，避免蜡像磨皮、过度锐化和塑料皮肤。
- 衣服的面料和轮廓应有明确质感（棉麻/针织/羊毛/丝绒）；品牌代言感来自造型秩序，不靠 logo 堆砌。
- 若用户说“不改原穿搭”，只调整光影/镜头可变项，禁止建议替换衣服。

### 5. 若有参考脸，执行身份锁定

将参考照片的唯一职责标为 `身份参考`；除非用户同意，不改变脸型、五官比例、肤色、发际线、发型及明确锁定的服装。

在多图系列中重复相同身份锁定段，允许改变表情、镜头和环境时分别列明。使用 [Identity Control](references/identity-control.md) 核对，不用虚假的“100% 一致”承诺。

### 6. 编写完整 Prompt

输出顺序：

```text
[目标] 图片种类、比例、摄影风格。
[主体] 成年人、身份约束（有参考图时）、姿态、面部状态。
[镜头] 景别、机位、人物在构图中位置、焦点与裁切。
[光线] 主光与阴影、背景亮度、反射控制。
[造型] 妆发、服装材质；明确不可改变项。
[质感] 真实皮肤、镜头细节、后期调色程度。
[限制] 不换脸、不多生肢体、不塑料磨皮、不错误裁切等当前风险。
```

Prompt 语言按用户要求；中文使用者默认输出中文完整可复制版。若用户明确要求英文或特定模型再适配措辞，不编造专用参数。

### 7. 质检

- [ ] 主体是明确成年人，参考身份是否被独立保留。
- [ ] 景别与裁切符合用户需求；没有把极近部分脸误写成完整居中半身。
- [ ] 视线、情绪、唇形与姿态可被视觉检验。
- [ ] 皮肤保留细节，但并非刻意夸张瑕疵。
- [ ] 光线方向一致，不发生互相冲突的阴影描述。
- [ ] 锁定的服装/发型/背景等没有被换掉。
- [ ] 不宣称没有看到的图片或生成效果已达到要求。

## 输出格式

默认顺序：`人物情绪定义 → 摄影方案（构图/镜头/光线/质感） → 完整 Prompt → 需检查的 3 个重点`。如果用户仅要 Prompt，直接给一段可复制的完整版本。

遇到“同一人换成 3/5 种人像风格”，先输出**共享身份锁定指令**，再列每张不同的镜头/光线变化，防止意外变成不同模特。

## 能力边界

- Prompt 本身不是身份保持算法；具体一致性取决于模型、参考素材、采样设置及反复筛选。
- 若没有图像编辑能力，输出的是生成/修改方案，并非真正的人像作品。
- 用户给的个人照片与商业素材须具备合法使用权限；不推断照片中人物的姓名或真实身份。

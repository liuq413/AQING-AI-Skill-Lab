# Identity Control · 参考人像身份一致性

## 锁定层级

1. **核心身份特征：**脸部轮廓、眉眼关系、鼻梁鼻翼结构、嘴唇轮廓、肤色、发际线。
2. **用户指定固定项：**服装、发型、妆容、眼镜、首饰、姿态、背景。只有用户指定才锁定。
3. **可变摄影变量：**景别、机位、背景光、表情、目光方向、色调。要明确哪些允许更改。

写作顺序：`使用参考图作为唯一身份参考 → 必须保持 A/B/C → 允许改变 D/E → 不要擅自换脸或过度美化`。

## 多图同人场景

- 先生成一份统一的身份约束段，在每张 Prompt 重复使用。
- 每张仅改变一个主要维度（例如情绪或机位），降低漂移风险。
- 三视图要求“正面/侧面/背面”时，脸在侧面不可见不等于身份漂移；需分别检查发型、体型、服饰连贯性。
- 九宫格表情：固定机位、服饰和光照，只改变微表情；相邻图不可换成新的面孔。

## 当参考图与新要求冲突

例如：`完全不换衣服` 与 `改成黑色风衣` 无法同时成立，必须确认最终优先级。不用模糊措辞绕过问题。

## 可复制身份锁定语句

```text
以用户上传的参考肖像作为唯一人物身份依据，尽量保持参考图人物的脸型比例、眼鼻唇结构、肤色、发际线与已确认的发型高度一致，不将人物美化成另一张脸。严格保留用户指定的原始穿搭、配饰与姿势；允许改变的仅为用户明确同意的镜头、光线、表情和背景。多人或多格构图中始终是同一位成年人物，不得复制出不相关人物。对参考图看不到或用户未指定的细节，不擅自编造为“原貌”。
```

## 检查与现实限制

- 看参考图与生成图是否存在五官比例、年龄感、肤色及发际线的明显变化。
- 若发现漂移：减少一次任务中同时变化的摄影变量，使用更清晰参考图和更稳定的构图；不只是把“100%一致”重复十次。
- 真实的参考图控制能力因工具而异，不能承诺逐像素相同；若需要 1:1 原样保留，应优先选择精确编辑、抠图或局部修图工具。

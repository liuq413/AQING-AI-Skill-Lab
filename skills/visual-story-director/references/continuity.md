# Continuity & Motion Logic · 动作连续性参考

## 1. 物件状态守恒

对每个重要物件追踪：`ID｜初始位置｜当前持有人/接触者｜动作触发｜最终位置`。重复出现同样视觉元素必须区分是**同一物件**还是新的物件。

- **禁止凭空产生：**开场空地→只有桌面被撞后图标才坠地。
- **禁止远程拾取：**手必须靠近、接触、抬起，物件才能离开原位置。
- **禁止远程复位：**放回图标要明确手持图标接近目标空位、贴合后松手，不是屏幕点击一下就复原。
- **禁止无原因消失：**易拉罐踢出后必须延续轨迹直到落地或进桶。

## 2. 空间一致性

优先用固定参照：人物前进方向、物件相对位置、入口/出口、镜头朝向。若发生镜头反打，标明方位变化。涉及踢/扔/接的动作，必须说明速度方向和目标位置，不用“酷炫地”取代轨迹。

## 3. 动作因果链

用 `前提 → 行为触发 → 身体姿态变化 → 接触/避让 → 结果` 表示。每个转折至少有一个观众看得见的节点：例如“低头走路”才导致“几乎撞杆”；躲过杆后看见罐才有“踢球”。

## 4. 时间与动作预算

对 15 秒成片，常见可读节拍：

- 0–3s 建立空间、人物意图；
- 3–7s 障碍与反应；
- 7–12s 核心表演动作；
- 12–15s 结果与情绪收束。

这是**叙事示例，不是模型限制**。镜头固定时让角色动作区分节拍；事件过多时优先合并次要动作。

## 5. Bug 分类 → 最小修正

| 现象 | 常见指令缺陷 | 修复方式 |
| --- | --- | --- |
| 道具瞬移 | 没有写接触与中间轨迹 | 补“手接触→拿起→携带→放下”的动作链 |
| 电线杆变到人物侧面 | 没给初始行进方向 | 标明固定参照与第一帧站位 |
| 角色多了一位 | 角色数量不固定 | 写明始终仅 N 位且背景无复制体 |
| 画面变换机位 | 只写了“电影感” | 明确镜头锁定和禁止切镜 |
| 情节讲不清 | 15 秒内事件太密集 | 保留一个核心笑点，必要时拆段 |

优先保留已成功生成的部分，不要求整体重设计。

# 视频提示词结构与模型适配

## 模型中性版本

把下述字段串成连贯自然语言即可，不要求模型识别标签字面值：

```text
规格：15秒，竖屏9:16，写实/3D风格，固定机位或明确切镜方式。
主体：角色数与身份固定；服装、配件、面部特征不得漂移。
环境：场景结构与光影基准，空间参照。
第一帧：准确列出出现的物体与缺席的物体。
动作：依时间顺序逐段描述可见行动及因果关系。
道具：每个道具必须被接触、带动、有连续轨迹，最终落点清楚。
镜头：机位、景别、运动边界。
负面：只禁止本任务高风险错误。
```

## 针对指定模型调整时

1. 若用户指定 Seedance 或其他生成工具，先保留原事件逻辑，不因适配改动事实。
2. 有参考图时声明每张图职责；对 @图N 的写法只采用用户实际平台支持的表达方式。
3. 不编造模型支持的秒数、最大素材数量、帧率、控制参数或 API JSON。
4. 若平台不稳定执行完整长动作，提出 `分段生成 → 关键帧衔接 → 剪辑合成`，但尊重用户若要求单段尝试。
5. 不将“已遵照提示词生成”当作已经检查过输出。

## 改写策略

不要“增加更多高级电影感描述”来修动作错误。先找到事件链缺失的节点，再补少量约束。例如：

- 弱：`人物帅气地避开电线杆，之后踢球。`
- 强：`电线杆从第一帧起固定在人物行进正前方。人物低头刷手机继续直行，抬眼发现即将相撞，先快速向左闪身绕过杆；站稳后看见杆前方地面的一只易拉罐，右脚踢中罐身，罐子沿地面向远处垃圾桶滚去并进入桶内。`

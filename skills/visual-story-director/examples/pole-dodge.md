# 案例：闪身避杆 → 踢罐进桶

**用户输入：**原创 3D 角色刷手机走路，电线杆就在前方。差点撞上时闪身避开，然后“浪子踢球”踢易拉罐进垃圾桶。15 秒，9:16。

**导演意图：**用“险些撞杆”和“意外神射”形成一个清晰的动作反差笑点。

| 时间 | 可观察动作 | 空间/物件状态 |
| --- | --- | --- |
| 0–4s | 角色边走边看手机，毫无防备 | 电线杆在行进正前方；易拉罐位于杆的前方地面；垃圾桶在更远处 |
| 4–7s | 角色抬眼意识到危险，朝左侧闪身绕杆 | 电线杆固定不动，角色真实改变行进路线 |
| 7–12s | 角色站稳、发现罐子、摆腿踢中罐身 | 易拉罐从原位置沿地面向垃圾桶运动 |
| 12–15s | 罐子进入垃圾桶，角色得意又装作平常 | 罐子不再出现在地上，垃圾桶接收罐子 |

## 可直接复制的 Prompt

```text
生成15秒竖屏9:16原创3D角色搞笑短片。全程同一个角色、同一套服装、同一条街道，画面空间连续、表演自然，动作方向一致。街道前景的人物朝画面深处边走边低头刷手机，第一帧一根电线杆已固定在人物继续直走会撞上的正前方；电线杆不会突然移动。电线杆前方地上已有一只完整易拉罐，远处正对易拉罐前进方向有一个垃圾桶。
0–4秒：人物专注看手机，脚步自然地朝电线杆走近，几乎要撞上。
4–7秒：人物突然抬头意识到危险，迅速向左侧闪身，身体侧转绕过电线杆并站稳，电线杆与人物全程保持合理的空间关系。
7–12秒：人物看见前方地面的易拉罐，微笑，调整步伐，用右脚明确踢中易拉罐；罐子受力沿地面向前滚动/滑行，运动方向直指远处垃圾桶。
12–15秒：易拉罐可见地进入垃圾桶，人物轻轻整理衣服，故作淡定地走开，形成幽默收尾。
必须能看清角色躲杆与脚触碰罐身的关键动作，不允许电线杆错位、人物穿模、易拉罐瞬移进桶、同一个罐子同时出现在地上与桶内，也不允许额外出现复制角色。保持统一画风与清晰动作逻辑。
```

**检查关键：**电线杆的初始相对位置；避让路径是否可读；脚是否真实碰到罐；罐子是否有完整去向。

*注：这是提示词和逻辑设计案例，不代表该视频已经在任何生成模型中测试通过。*

# 案例：桌面图标必须“被撞倒”且“被放回”

**用户输入：**两只原创小动物在桌面玩耍，撞倒屏幕侧边一列实体化图标，主角逐个拾起拼回原位置。开头地上没有图标。固定 16:9 桌面场景。

## 事件链

1. **首帧：**桌面所有图标完整排列，地面干净、无图标；左侧两角色正在玩耍。
2. **触发：**两角色撞到图标列，图标真实倒塌并落到地面。
3. **拾取：**主角弯腰伸手、接触其中一枚图标、拿起来。
4. **复位：**主角将手里的图标移到它对应的空位，准确对齐后松开手，屏幕/桌面图标状态同步变化。
5. **结束：**地面图标数量逐渐减少，最后归零；各图标只有一个实体，不自发复制。

## Prompt 片段（可嵌入完整叙事）

```text
开头地上绝对没有散落图标。图标只在两只原创角色玩耍碰撞到左侧图标列之后，才从原本位置掉落地面。主角必须逐个完成“弯腰→手指触碰图标→把图标拿起来→移动到对应空缺位置→放入→松手”的完整物理动作；手中的图标不能凭空消失，目标位置不能提前自动复原。每放回一个，地面的图标减少一枚，原位恢复一枚。镜头固定16:9，空间位置保持连续。
```

**易错与修复：**如果生成片里“在手上点一下→图标消失→右边自动归位”，不要泛泛强化“真实感”；必须补齐中间位移和手部松开的动作。

# 设计质量闸门 / Quality Gates

> 检查是为了找到明确修复动作；不要用无法衡量的“高级一点”作为唯一反馈。

## 阶段 A · 概念

- 是否能用 1 句话说清主张？
- 主视觉是否直接服务该主张？
- 用户给的参考属于材质、结构还是人物？是否越界？

## 阶段 B · 构图

- 缩小到手机缩略图，是否一眼可见主体？
- 主视觉是否有可辨识的轮廓、尺度和对比？
- 是否为后排版真实留白，而不是文字即将遮挡重要内容？
- 场景/绿植/建筑是否与主体抢占视觉空间？

## 阶段 C · 可生成性

- 是否清楚交代前景、中景、背景的关系？
- 材质词是否互相矛盾（纸艺却要求金属镜面）？
- 是否有难以同时满足的极端构图/细小物件？
- 禁止项是否聚焦现实常见错误（logo、文字乱码、重复角色）？

## 阶段 D · 精准修改

如果用户说“只把药店放大一些，人物不动”，修复说明应是：`把右侧药店整体放大约 10–15%，保持其余构图、人物、车辆比例和光影不变`；不要顺便添加装饰、换颜色或重构城市背景。**数值只在用户接受近似幅度且有合理基准时给；精确编辑必须以图像工具实测。**

## 可执行反馈范式

`问题定位 → 视觉后果 → 最小修复指令 → 不可变项`。

例如：`主体右侧堆满枝叶 → 视线偏离主标题区 → 删除右侧两组细小绿植，保留主体与色调 → 不修改人物、核心建筑和图幅比例。`

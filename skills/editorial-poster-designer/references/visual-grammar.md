# AQING Poster Visual Grammar · 视觉语法

## 1. 画面组成

| 层级 | 负责的事 | 常见错误 |
| --- | --- | --- |
| 主视觉 | 3 秒内传达主题或情绪 | 过多人物/道具争焦点 |
| 承托环境 | 交代空间/文化/品牌气质 | 大量建筑绿植挤占视线 |
| 辅助装饰 | 引导阅读与强化符号 | 花纹、光效、贴纸互相冲突 |
| 文字安全区 | 为标题、信息提供可读区域 | 背景细节密、对比过高 |

## 2. 5 种可复用构图

1. **单物体巨幅尺度：**主体 60–80% 的视觉占比，环境简化；适合品牌 KV 与概念图。
2. **瑞士非对称网格：**重心偏左/右；文字若后期排版，则保留完整网格区；适合编辑海报。
3. **上下等分对照：**1:1 两个语义对应场域，严格区分而非任意拼贴。
4. **视觉从边缘闯入：**大幅近景裁切，形成动势和自媒体识别。
5. **中央负空间：**外围视觉元素朝空心区域组织；适合标题/神秘概念。

这些不是可随意叠加的装饰选项，每次选符合传播目标的主体结构。

## 3. 配色层级

- 主色：决定整体情绪，用于背景或主视觉大块面。
- 平衡色：缓和大面积主色的偏向，不应再次主导。
- 缓冲色：白/米/灰等休息空间，帮助阅读。
- 强调色：小面积焦点，通常少而准确。
- 锚点色：深色控制暗部重量，避免整张发飘。

具体 HEX 只在用户需要或品牌规范明确时给出。先说明色彩比例逻辑，不虚构“品牌标准色”。

## 4. 风格转译样表

| 风格 | 画面执行要点 | 避免 |
| --- | --- | --- |
| Swiss editorial | 非对称网格、极大/极少的字号层级、留白、清楚对齐 | 用几何色块铺满 |
| Paper diorama | 多层纸张、折边、可见厚度、实景柔光阴影 | 塑料般无边缘纸片 |
| 3D soft clay | 体积可读、圆润转角、统一表面粗糙度 | 一切磨成过亮玩具 |
| Risograph | 有限墨色、微错印、网点密度有起伏 | 泛滥砂砾遮挡细节 |
| Grating optical | 连续平行线形成受控压缩/膨胀，少量大的形变区 | 直接画写实轮廓或到处扭曲 |
| Minimal ink line | 清楚主形、少数笔触、淡墨层次、留白 | 乱线拼贴 | 

## 5. 后期排版预留

如文案复杂：先生成纯视觉底图，指定空区 `顶部 20%` / `右侧 30%` 等结构，而不是让模型硬生成文字。正式交付需在设计软件中检验标题字数、换行、对齐与小屏可读性。

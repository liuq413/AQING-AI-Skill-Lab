# 案例：光栅变形实验海报

**目标：**设计一张以平行线条挤出“隐藏三维物体”的纯视觉实验海报，3:4，无字。

**设计机制：**主题不是靠直接画轮廓，而是通过密集线场受局部体积挤压后发生连续变形；远离主体的位置恢复平直。

## 可复制 Prompt

```text
生成一张3:4竖版黑白实验平面海报，纯视觉，无标题、文字、logo或水印。整体画面由均匀、细密、连续的水平平行黑色光栅线条构成，奶白纸面背景，呈现平面印刷与现代视觉研究的精确质感。画面中央约75%的区域隐藏着一个有体积的抽象球状形态；球体不通过实线外轮廓、写实阴影或3D物体渲染出现，而是由平行线条在局部平滑压缩、外扩、弯曲、疏密变化而被感知。仅保留两到三个大的、受控制的线条形变区域。越接近四周边缘，所有线条越自然地恢复平直平行。画面留白干净，线条精细清晰，黑白对比稳定，带微弱高质量纸张触感，禁止零碎噪点与复杂装饰。
```

**质检：**线条是连续变形而非“球体覆盖在线条上”；远离主体的线条恢复水平；没有三维写实轮廓。
